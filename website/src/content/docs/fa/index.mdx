## نصب سریع

<div class="install">

```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/javadtifusi-eng/Tifusi-Panel/main/install.sh)"
```

</div>

روی Ubuntu یا Debian با کاربر root اجرا کنید. برای MySQL، گزینهٔ `-- --pro` را اضافه کنید. [راهنمای نصب](guides/installation/)

## مجوز استفاده

استفاده روی سرور شخصی آزاد است. بازنشر، تغییر نام یا فروش به اجازهٔ کتبی نیاز دارد. [متن مجوز](https://github.com/javadtifusi-eng/Tifusi-Panel/blob/main/LICENSE)
