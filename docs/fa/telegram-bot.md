# ربات تلگرام (Tifusi Bot)

[Tifusi Bot](https://github.com/javadtifusi-eng/Tifusi-Bot) یک فروشگاه تلگرامی برای فروش اشتراک‌های تیفوسی پنل است. ربات کاربران را از طریق API پنل می‌سازد و تمدید می‌کند، بنابراین فروش به هیچ کار دستی در داشبورد نیاز ندارد.

## نحوه‌ی کار با پنل

۱. مشتری یک سرویس و سپس یک پلن انتخاب می‌کند و نام کاربری دلخواهش را می‌فرستد.

۲. ربات مبلغ را از کیف پول مشتری کسر می‌کند، کاربر را روی کم‌بارترین پنل می‌سازد و کد دسترسی، لینک اشتراک و کد QR را تحویل می‌دهد.

۳. تمدید همیشه همان کاربر را روی همان پنل تمدید می‌کند؛ کد، لینک و QR تغییری نمی‌کنند.

ربات فقط سرویسی را می‌فروشد که پنل برای آن هاست داشته باشد:

| سرویس در ربات | پروتکل‌های پنل |
| --- | --- |
| Xray | VLESS، VMess، Trojan، Shadowsocks |
| Hysteria2 | Hysteria2 |
| IKEv2 | IKEv2 |
| L2TP | L2TP |

مشتری‌ای که یک سرویس را می‌خرد فقط به همان پروتکل دسترسی می‌گیرد. پروتکل‌هایی که به پنل اضافه یا از آن حذف می‌شوند هر پنج دقیقه به‌صورت خودکار شناسایی می‌شوند.

## اتصال پنل به ربات

در ربات، مسیر **مدیریت پنل‌ها ← افزودن پنل** را باز کنید و نام، نشانی پنل و نام کاربری و رمز یک مدیر پنل را وارد کنید. ربات اتصال را آزمایش می‌کند، پروتکل‌ها و گروه‌های پنل را می‌خواند و می‌پرسد هر سرویس از کدام گروه استفاده کند؛ سپس موقعیت و ظرفیت کاربر را تعیین می‌کنید. می‌توان چند پنل اضافه کرد؛ هنگامی که یکی پر شود، خریدهای جدید به پنل بعدی منتقل می‌شوند.

## امکانات

| بخش | توضیح |
| --- | --- |
| فروشگاه پلن | پلن‌های هر سرویس با حجم، مدت، قیمت و محدودیت دستگاه مستقل. |
| تحویل | کد QR همراه با لینک اشتراک، پروفایل آیفون، کد دسترسی و اطلاعات ورود IKEv2/L2TP. |
| کیف پول | شارژ با ارسال رسید پرداخت و تأیید یا رد آن توسط مدیر. |
| یادآوری | پیام خودکار سه روز و یک روز پیش از انقضا و در روز انقضا، همراه با دکمه‌ی تمدید. |
| حساب تست | یک بار برای هر کاربر؛ به‌طور پیش‌فرض غیرفعال. |
| پیام همگانی | ارسال متن یا عکس به همه‌ی کاربران با سرعتی که تلگرام می‌پذیرد. |
| پشتیبان‌گیری | پشتیبان فوری و روزانه، و بازیابی از داخل ربات. |

## نصب

روی سرور Ubuntu 20.04 یا بالاتر، با دسترسی root:

</div>

```bash
bash <(curl -Ls https://raw.githubusercontent.com/javadtifusi-eng/Tifusi-Bot/main/install.sh)
```

<div dir="rtl">

نصب‌کننده توکن ربات و شناسه‌ی تلگرام مدیر را می‌پرسد، یک سرویس systemd می‌سازد و منوی `tifusi bot` را اضافه می‌کند. روی سروری که پنل هم نصب است، `tifusi panel` و `tifusi bot` از همان راه‌انداز، منوی مخصوص خود را باز می‌کنند.
