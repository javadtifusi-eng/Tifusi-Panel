# تانل‌ها

کاربر به سرور ایران وصل می‌شود و ترافیک از تانل به سرور خارج می‌رود. اتصال را سرور خارج برقرار می‌کند، پس سرور خارج پورت ورودی باز لازم ندارد.

## ساخت تانل

1. **تانل‌ها ← تانل جدید:** نشانی و پورت سرور ایران (پیش‌فرض `8443`)، سرور خارج (نود پنل یا هر سرور)، ترنسپورت و پورت‌های فوروارد (TCP یا UDP).
2. **ذخیره.** پنل برای هر سمت دستور نصب می‌سازد.
3. **نصب:** دستور هر سمت را روی همان سرور اجرا کنید، یا **🔑 نصب با SSH** را بزنید تا پنل خودش نصب کند (اگر سرور به گیت‌هاب دسترسی نداشت، بسته‌ی آفلاین را می‌فرستد).
4. **تست اتصال** را بزنید. کارت سبز یعنی تانل وصل است.

برای روز قطعی، **فایل نصب آفلاین سرور ایران** را از همین حالا دانلود کنید.

## ترنسپورت

| ترنسپورت | کِی |
| --- | --- |
| **TCP چندگانه** | پیش‌فرض؛ سریع‌ترین. |
| **TCP + Stealth** | وقتی TCP ساده شناسایی و قطع می‌شود. |
| **WSS چندگانه** | وقتی IP سرور ایران فیلتر است؛ تنها گزینه‌ی عبور از CDN. |
| **UDP (KCP)** | خط پرقطعی یا پکت‌لاس بالا. |
| **Spoof** | اینترنت ملی (لیست سفید). |

**پیشنهاد بهترین ترنسپورت** در فرم، دو سرور را می‌سنجد و ترنسپورت‌ها را رتبه‌بندی می‌کند. نتیجه را بعد از نصب با تست واقعی تأیید کنید.

## عبور از CDN

با **WSS چندگانه**، تیک **عبور از CDN** را بزنید، ابر آروان یا Cloudflare را انتخاب کنید و دامنه‌ای را بدهید که به سرور ایران اشاره می‌کند. چک‌لیست زیر فرم را انجام دهید (رکورد A با پروکسی روشن، HTTPS به مبدأ، WebSocket روشن).

دکمه‌ی **⚡ کیفیت ابر آروان** بهترین IPهای لبه و SNI را پیدا می‌کند و سرعت واقعی را می‌سنجد. ترافیک ابر آروان هزینه دارد.

## تانل Spoof

برای اینترنت ملی: بسته‌ها با نشانی مبدأ جعلی از لیست سفید رد می‌شوند.

1. اول کارت **تست IP Spoofing** را در هر دو جهت اجرا کنید. اگر دیتاسنتر بسته‌ی جعلی را بیرون ندهد، این تانل کار نمی‌کند.
2. تانل را با ترنسپورت **Spoof** بسازید: مبدأ جعلی (یک نشانی، لیست یا رنج) و حامل (UDP، ICMP، ICMPv6 یا TCP).
3. اگر ICMP بسته بود، ICMPv6 را امتحان کنید. Spoof فقط IPv4 است.

## موارد دیگر

- **IKEv2 و L2TP:** پورت‌های UDP ‏500 و 4500 (و 1701 برای L2TP) را فوروارد کنید. هاست باید به نشانی سرور ایران اشاره کند.
- **IP واقعی کاربر:** تیک **IP واقعی (PROXY)** روی فوروارد TCP، و `acceptProxyProtocol: true` روی یک inbound جدای Xray.
- **زنجیره:** **تانل‌ها ← 🔗 زنجیره‌ها**، برای عبور از چند سرور پشت‌سرهم؛ هر هاپ ترنسپورت خودش را دارد.
- **آپدیت:** **🔄 آپدیت تانل**؛ اگر تانل بالا نیاید، خودکار به نسخه‌ی قبل برمی‌گردد.

جزئیات فنی: [معماری](architecture.md#تانلها).

## تنظیمات پیشرفته

برای بیشتر سرورها حالت **متعادل** کافی است. بعد از هر تغییر، **نصب/آپدیت** را بزنید (کاربران چند ثانیه قطع می‌شوند).

| تنظیم | پیش‌فرض | کِی عوض کنید |
| --- | --- | --- |
| تعداد کانکشن | ۸ | خطای «no tunnel connection available»: ۳۲ تا ۱۲۸ |
| آدرس اتصال به ایران | خالی | IPv4 ایران از خارج بسته است: IPv6 ایران |
| پنجره‌ی KCP | ۱۰۲۴ | رم سرور خارج پر می‌شود: ۲۵۶ |
| FEC | ۱۰ و ۳ | خط پرقطعی: کمکی ۴ یا ۵ |

## عیب‌یابی

| نشانه | راه‌حل |
| --- | --- |
| قطع‌ووصل پشت‌سرهم | ترنسپورت را به TCP چندگانه، بعد UDP عوض کنید. |
| وصل ولی کُند | **تست لینک**؛ اگر پکت‌لاس دارد، UDP (KCP). |
| خارج به ایران وصل نمی‌شود | IPv6 ایران در «آدرس اتصال به ایران». |
| دانلود حجیم وسط کار قطع می‌شود | هر دو سمت را آپدیت کنید. |
| Stealth وصل نمی‌شود | ساعت دو سرور را هماهنگ کنید. |
| فقط یک کشور بد است | مشکل از سرور همان کشور است. |
