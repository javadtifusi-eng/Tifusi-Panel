# هسته‌ها و هاست‌ها

**هسته** سرویسی است که روی نود اجرا می‌شود. **هاست** لینکی است که کاربر می‌گیرد. **گروه** تعیین می‌کند هر کاربر کدام هاست‌ها را ببیند.

## ساخت هسته

1. **هسته‌ها ← هسته‌ی جدید** و نوع را انتخاب کنید: Xray، IKEv2، L2TP، PPTP، Hysteria2 یا WireGuard.
2. برای Xray، کانفیگ JSON را وارد کنید (همان که `xray run -c` می‌پذیرد). inboundها خودکار استخراج می‌شوند. تنظیمات REALITY هم همین‌جا وارد می‌شود.
3. روی کارت هسته، نودهایی را که باید اجرایش کنند انتخاب کنید.

هسته‌ای که روی [پورت رزرو](updates-and-rollback.md) باشد ذخیره نمی‌شود.

## ساخت هاست

1. **هاست‌ها ← هاست جدید:** پروتکل، inbound (یا هسته برای IKEv2 و L2TP)، نشانی، پورت و نام نمایشی.
2. در صورت نیاز SNI، fingerprint، path و ALPN را برای کلاینت عوض کنید.

چند هاست روی یک inbound، نسخه‌های مختلف یک لینک‌اند و در یک کارت جمع می‌شوند.

### متغیرهای نام هاست

دکمه‌ی `{ }` در کادر نام، متغیر درج می‌کند؛ مثلاً `🇩🇪 {server_name} | {days_left} روز`.

| متغیر | مقدار |
| --- | --- |
| `{username}` | نام کاربر |
| `{days_left}` | روزهای باقی‌مانده |
| `{expiry_date_fa}` / `{expiry_date_en}` | تاریخ انقضا، شمسی / میلادی |
| `{remaining_traffic}` / `{used_traffic}` / `{total_traffic}` | حجم |
| `{server_name}` / `{protocol}` / `{status}` | سرور، پروتکل، وضعیت |

## Hysteria2

هسته‌ی UDP کنار Xray، برای شبکه‌ای که پروتکل‌های TCP رویش ضعیف‌اند. رمز هر کاربر همان secret اشتراک اوست.

**راه‌اندازی**

1. **هسته‌ها ← Hysteria2 ← هسته‌ی جدید:** پورت UDP، رمز استتار (salamander) و سقف نرخ (خالی یعنی بدون سقف؛ روی همراه اول ۱۵ مگابیت بهترین بود).
2. روی کارت هسته، نود را انتخاب کنید. ایجنت نود سرور Hysteria2 را خودش اجرا می‌کند.
3. **هاست‌ها ← هاست جدید** با پروتکل Hysteria2 روی همان هسته. نشانی و SNI باید با گواهی TLS نود جور باشد.

**انتخاب پورت** (اندازه‌گیری روی همراه اول؛ فقط پورت عوض شد)

| پورت UDP | نتیجه |
| --- | --- |
| ۴۴۳ | کاملاً مسدود |
| ۵۳ | دانلود حدود ۳ مگابیت |
| ۱۱۹۴، ۵۱۸۲۰ | حجم خوب، تأخیر بد |
| **۸۸۰۱** (Zoom) | **دانلود ۴۰، آپلود ۳٫۵ مگابیت** |

گزینه‌های بعدی اگر ۸۸۰۱ محدود شد: ۳۴۷۸ و ۱۹۳۰۲.

**محدودیت‌ها**

- هر نود یک هسته‌ی Hysteria2.
- فعلاً فقط روی نودِ ماشین خود پنل، چون از گواهی پنل (`/opt/tifusi-panel/certs`) استفاده می‌کند.
- بدون استتار، از داخل ایران وصل نمی‌شود.
- حجم کاربر شمرده می‌شود و کاربر منقضی یا غیرفعال قطع می‌شود.

## گروه‌ها

- هاست یا inbound **بدون گروه** برای همه‌ی کاربران است.
- هاست **با گروه** فقط به اعضای همان گروه داده می‌شود.
- برای امتحان یک لینک تازه (پورت دیگر، IP تمیز) روی چند کاربر، به آن هاست یک گروه اختصاصی بدهید (🔒).
