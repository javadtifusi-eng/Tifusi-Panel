# نودها

نود سرور خارجی است که کاربران مستقیم به آن وصل می‌شوند. پنل فقط پیکربندی را به نود می‌فرستد و ترافیک کاربران از پنل عبور نمی‌کند.

> نود همیشه روی سرور **خارج از ایران** نصب می‌شود. روی سرور ایران فقط سمت ایرانِ [تانل](tunnels.md) نصب می‌شود.

## افزودن نود

1. **نودها ← نود جدید:** نشانی سرور و پورت ایجنت (پیش‌فرض `62050`).
2. دستور نصبی را که پنل نشان می‌دهد روی سرور نود اجرا کنید، یا دکمه‌ی **SSH** را بزنید تا پنل خودش نصب کند (رمز فقط برای اتصال اول لازم است و ذخیره نمی‌شود).
3. **همگام‌سازی** را بزنید. نود سبز یعنی آماده است.
4. در صفحه‌ی [هسته‌ها](cores-and-hosts.md)، هسته را به این نود وصل کنید.

## هسته‌های هر نود

هر نود شش جایگاه مستقل دارد و هر کدام می‌تواند خالی بماند:

| جایگاه | سرویس |
| --- | --- |
| Xray | VLESS، VMess، Trojan، Shadowsocks و REALITY |
| IKEv2 | کلاینت‌های بومی گوشی و ویندوز |
| L2TP و PPTP | کلاینت‌های قدیمی |
| Hysteria2 | UDP، برای شبکه‌های ضعیف |
| WireGuard | کلاینت‌های WireGuard |

## مدیریت و آپدیت

- **ترمینال:** در شیت **SSH** هر دستوری روی نود اجرا می‌شود، با دکمه‌های آماده برای لاگ، ری‌استارت، دیسک و فایروال.
- **آپدیت:** تب **آپدیت** برای یک نود، یا **🔄 آپدیت تدریجی نودها** برای همه. اگر نسخه‌ی جدید بالا نیاید، خودکار برمی‌گردد. [به‌روزرسانی امن](updates-and-rollback.md)
- **روی خود سرور:** `tifusi node status|logs|restart|update|uninstall`
- **حذف نود:** اول `tifusi node uninstall` روی سرور، بعد حذف از صفحه‌ی نودها.
- **نصب آفلاین:** با `tifusi panel node-bundle` روی سرور پنل بسته بسازید و در شیت SSH روش **آفلاین** را انتخاب کنید.

## نود جایگزین

وقتی IP نود بسته شد یا سرور عوض می‌شود، کاربران بدون تغییر پروفایل به سرور جدید منتقل می‌شوند:

1. سرور جدید را به‌عنوان نود اضافه کنید تا **متصل** شود.
2. روی نود قدیمی **نود جایگزین** را بزنید، مقصد را انتخاب و **بررسی سازگاری** را اجرا کنید.
3. **آماده‌سازی مقصد** را بزنید و اتصال یک کاربر را روی آدرس جدید تست کنید.
4. رکورد DNS را خودتان روی آدرس جدید بگذارید، بعد **تأیید انتقال**.

**برگشت به نود قبلی** در هر مرحله ممکن است. Xray، IKEv2، L2TP و PPTP منتقل می‌شوند؛ Hysteria2، WireGuard و نودهای پشت تانل فعلاً نه.

## نکته‌ها

- **محدودیت دستگاه** روی خود نود اعمال می‌شود: دستگاه اضافه تا خالی شدن جا منتظر می‌ماند.
- **کانفیگ خراب** اعمال نمی‌شود: نود با کانفیگ قبلی می‌ماند و دلیل خطا روی صفحه‌ی نود نمایش داده می‌شود.
