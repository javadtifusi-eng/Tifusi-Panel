# مدیریت و عملیات

## فرمان مدیریت

فرمان `tifusi panel` بدون آرگومان یک منوی تعاملی و با آرگومان یک عملیات مشخص را اجرا می‌کند:

| فرمان | عملیات |
| --- | --- |
| `tifusi panel update` | به‌روزرسانی به آخرین نسخه و ساخت دوباره‌ی کانتینرها |
| `tifusi panel status` | نمایش وضعیت کانتینرها |
| `tifusi panel logs` | دنبال کردن لاگ کانتینرها |
| `tifusi panel restart` | راه‌اندازی دوباره‌ی مجموعه |
| `tifusi panel port` | تغییر پورت‌های API پنل و داشبورد |
| `tifusi panel ssl` | صدور گواهی Let's Encrypt |
| `tifusi panel key` | تولید کلید راه‌اندازی جدید برای مدیر |
| `tifusi panel backup` / `tifusi panel restore` | پشتیبان‌گیری یا بازیابی پایگاه داده |
| `tifusi panel uninstall` | حذف نصب |

فرمان `tifusi` یک راه‌انداز مشترک با [Tifusi Bot](telegram-bot.md) است: `tifusi bot` منوی نصب‌کننده‌ی ربات را باز می‌کند و `tifusi app` آخرین نسخه‌ی [Tifusi VPN](android-app.md) را همراه با لینک دانلود نمایش می‌دهد. اگر روی سرور تنها یکی از پنل یا ربات نصب باشد، `tifusi` بدون زیرفرمان همان را باز می‌کند؛ از این رو `tifusi update` همچنان کار می‌کند.

سرورهای نود منوی `tifusi node` مخصوص خود را دارند؛ بخش [نودها](nodes.md) را ببینید.

## مدیران

پنل یک حساب مالک و هر تعداد مدیر اضافی با مجوزهای محدود روی کاربران، هاست‌ها، نودها، هسته‌ها، گروه‌ها، تانل‌ها و تنظیمات دارد. مدیر محدود فقط کاربرانی را می‌بیند که خود ساخته است. هر مدیر می‌تواند برای خودکارسازی کلید API صادر کند؛ کلید همیشه مجوزهای فعلی صاحبش را دارد. [نمایندگان](resellers.md) نوع جداگانه و محدودتری از حساب هستند.

## اعلان‌ها

تغییر وضعیت کاربران و نودها را می‌توان به تلگرام، دیسکورد یا یک webhook عمومی ارسال کرد.

## تنظیمات

نشانی عمومی، رمز مدیر، گواهی TLS (بارگذاری یا صدور Let's Encrypt) و پشتیبان‌گیری و بازیابی پایگاه داده همگی از بخش **تنظیمات** تغییر می‌کنند و بدون استقرار دوباره اعمال می‌شوند. پشتیبان‌گیری بخش تنظیمات برای نسخه‌ی عادی است؛ در نسخه‌ی حرفه‌ای از `tifusi panel backup` استفاده کنید که خروجی MySQL را هم شامل می‌شود.
