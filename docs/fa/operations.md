# مدیریت

## فرمان مدیریت

`tifusi panel` بدون آرگومان منو باز می‌کند:

| فرمان | کار |
| --- | --- |
| `update` | آپدیت با برگشت خودکار |
| `status` / `logs` / `restart` | وضعیت، لاگ و ری‌استارت |
| `port` / `ssl` | تغییر پورت، گواهی Let's Encrypt |
| `key` | کلید ورود جدید برای مدیر |
| `backup` / `restore` | بکاپ و بازیابی |
| `node-bundle` | ساخت بسته‌ی نصب آفلاین نود |
| `remove-node` | حذف یک نود از این پنل |
| `path` | مسیر مخفی داشبورد |
| `env` | ویرایش فایل تنظیمات (`.env`) |
| `uninstall` | حذف نصب |

`tifusi bot` منوی [ربات](telegram-bot.md) و `tifusi node` منوی [نود](nodes.md) را باز می‌کند.

## بکاپ

</div>

```bash
tifusi panel backup
```

<div dir="rtl">

آرشیو شامل دیتابیس (و MySQL)، `.env` و گواهی‌هاست. آن را خصوصی نگه دارید و یک نسخه بیرون از سرور داشته باشید. در نسخه‌ی عادی، **تنظیمات** هم دکمه‌ی بکاپ و بازیابی دیتابیس دارد. قبل از بازیابی، بکاپ تازه بگیرید.

## مدیران

- **مالک** همه‌کاره است. **مدیر محدود** فقط بخش‌هایی را می‌بیند که اجازه دارد، و فقط کاربرانی را که خودش ساخته.
- هر مدیر می‌تواند **کلید API** بسازد؛ تغییر رمز کلیدها را باطل می‌کند.
- [نمایندگان](resellers.md) نوع جدا و محدودتری از حساب‌اند.

## ورود

- **رمز** با **کد دومرحله‌ای** اختیاری.
- **گوگل یا گیت‌هاب:** مالک یک بار Client ID و Secret را در **تنظیمات ← ورود با گوگل و گیت‌هاب** وارد می‌کند؛ بعد هر مدیر حساب خودش را وصل می‌کند.
- **مرا به خاطر بسپار** ورود را تا ۳۰ روز نگه می‌دارد. **خروج از همه‌ی دستگاه‌ها** همه‌ی ورودها را باطل می‌کند.

## اعلان‌ها و تنظیمات

- تغییر وضعیت کاربران و نودها، و پایان هر آپدیت، به تلگرام، دیسکورد یا webhook ارسال می‌شود.
- نشانی عمومی، رمز، گواهی TLS و بکاپ از **تنظیمات** و بدون نصب دوباره عوض می‌شوند.
