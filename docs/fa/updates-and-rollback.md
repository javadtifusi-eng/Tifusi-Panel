# به‌روزرسانی امن

هر آپدیت قبل از اعمال تست می‌شود و نسخه‌ی قبلی نگه داشته می‌شود. اگر نسخه‌ی جدید بالا نیاید، خودکار برمی‌گردد.

## آپدیت پنل

روی سرور پنل:

</div>

```bash
tifusi panel update
```

<div dir="rtl">

قبل از آپدیت از ایمیج‌ها و دیتابیس snapshot گرفته می‌شود. اگر پنل جدید ظرف ۹۰ ثانیه سالم بالا نیاید، نسخه‌ی قبلی برمی‌گردد. قبل از آپدیت‌های بزرگ، [بکاپ](operations.md) هم بگیرید.

## آپدیت نودها

- **یک نود:** شیت **SSH** نود ← تب **آپدیت**.
- **همه‌ی نودها:** صفحه‌ی نودها ← **🔄 آپدیت تدریجی نودها**. نود اول (Canary) بیشتر زیر نظر می‌ماند و با اولین خطا کار متوقف می‌شود.

نود ایمیج جدید را اول تست می‌کند و اگر ایجنت یا سرویسی که سالم بود بالا نیاید، به ایمیج قبلی برمی‌گردد. کاربران هر نود چند ثانیه قطع و خودکار وصل می‌شوند.

## آپدیت تانل

شیت **SSH** تانل ← **🔄 آپدیت تانل** برای هر سمت. اگر سرویس بالا نماند یا لینک‌ها ظرف ۴۵ ثانیه برنگردند، باینری قبلی برمی‌گردد. کانفیگ تانل تغییر نمی‌کند.

## کانفیگ نود

هر تغییر کاربر یا هسته کانفیگ تازه به نود می‌فرستد. کانفیگ خراب اعمال نمی‌شود؛ نود با کانفیگ قبلی کار می‌کند و دلیل خطا روی صفحه‌ی نود نمایش داده می‌شود.

## پورت‌های رزرو

هسته‌ای که از این پورت‌ها استفاده کند ذخیره نمی‌شود:

| پورت | استفاده |
| --- | --- |
| 62050 (یا پورت ایجنت نود) | ایجنت نود |
| 22 | SSH |
| 10085، 10087، 9998 | API آمار Xray، WireGuard و Hysteria2 |

## گزارش در تلگرام

پایان هر آپدیت پنل، نود یا تانل، با نتیجه و مدت زمان، به چتی که در **تنظیمات ← اعلان‌های تلگرام** تعیین شده گزارش می‌شود.

جزئیات فنی: [معماری](architecture.md#بهروزرسانی-امن).
