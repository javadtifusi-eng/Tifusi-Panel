# نصب

## پیش‌نیازها

- **سیستم‌عامل:** Ubuntu 22.04/24.04 یا Debian 11/12، معماری x86_64، دسترسی root و IPv4 عمومی.
- **دامنه:** برای TLS توصیه می‌شود؛ پورت ۸۰ برای گواهی Let's Encrypt باز باشد.

| نقش | حداقل | پیشنهادی |
| --- | --- | --- |
| پنل | ۱ CPU، ۱ گیگ رم، ۱۰ گیگ دیسک | ۲ CPU، ۲ گیگ رم، ۲۰ گیگ دیسک |
| نود | ۱ CPU، ۵۱۲ مگ رم، ۱۰ گیگ دیسک | ۱ CPU، ۱ گیگ رم، ۲۰ گیگ دیسک |
| پنل و نود روی یک سرور | ۱ CPU، ۲ گیگ رم، ۱۵ گیگ دیسک | ۲ CPU، ۲ گیگ رم، ۲۵ گیگ دیسک |
| پنل حرفه‌ای (MySQL) | ۲ CPU، ۲ گیگ رم، ۲۰ گیگ دیسک | ۲ CPU، ۴ گیگ رم، ۴۰ گیگ دیسک |

## نصب پنل

**نسخه‌ی عادی:**

</div>

```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/javadtifusi-eng/Tifusi-Panel/main/install.sh)"
```

<div dir="rtl">

**نسخه‌ی حرفه‌ای (MySQL)،** برای تعداد کاربر زیاد:

</div>

```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/javadtifusi-eng/Tifusi-Panel/main/install.sh)" -- --pro
```

<div dir="rtl">

نصب‌کننده Docker، گواهی و دستور مدیریتی `tifusi panel` را آماده می‌کند.

نصب‌کننده می‌پرسد نود روی همین سرور نصب شود یا نه؛ پیش‌فرض **نه** است.

## ساخت حساب مالک

1. داشبورد را باز کنید؛ صفحه‌ی ورود، راه‌اندازی را نشان می‌دهد.
2. روی سرور پنل کلید یک‌بارمصرف بگیرید:

</div>

```bash
tifusi panel key
```

<div dir="rtl">

3. کلید را وارد کنید و نام کاربری و رمز مالک را بسازید.

## قدم بعد

1. [نود اضافه کنید](nodes.md).
2. [هسته و هاست بسازید](cores-and-hosts.md).
3. [اولین کاربر را بسازید](users-and-subscriptions.md) و اتصال را روی گوشی تست کنید.

چک‌لیست داشبورد همین قدم‌ها را نشان می‌دهد.

## انتقال به سرور دیگر

**تنظیمات ← انتقال به سرور دیگه** (فقط مالک) پنل یا یک نود را با SSH به سرور تازه می‌برد و مشتری‌ها در تمام مدت وصل می‌مانند.

- **پنل:** اطلاعات، گواهی‌ها و تنظیمات کپی می‌شوند. بعد رکورد DNS را عوض کنید و تا تست سبز نشده **تمام** را نزنید. **برگردون** پنل قبلی را برمی‌گرداند.
- **نود:** ایجنت با همان کلید روی سرور تازه نصب می‌شود. لینک‌هایی که با IP قبلی داده شده‌اند باید دوباره داده شوند؛ پس در هاست‌ها دامنه بگذارید.
- **نسخه‌ی MySQL** را با `tifusi panel backup` و `tifusi panel restore` منتقل کنید.
